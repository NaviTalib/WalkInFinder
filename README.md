## ✨ Features

- **Verified Walk-in Drives:** Browse legitimate corporate walk-ins, interviews, and hiring events.
- **Post Openings:** Employers and coordinators can easily list new walk-in opportunities with complete role, date, and venue details.
- **Interactive User Profiles:** Manage user sessions, track account activity, and view posted drives.
- **Modern Responsive UI:** Built with Tailwind CSS and Lucide icons, featuring a sleek dashboard experience across mobile and desktop devices.
- **SEO & Social Preview Optimized:** Configured with custom meta tags, Open Graph cards, dynamic sitemaps, and clean SPA routing.

---

## 🛠️ Tech Stack

### **Frontend**
- **React (Vite)** - Fast, modern single-page application framework
- **React Router DOM** - Client-side routing
- **Tailwind CSS** - Utility-first styling and layout
- **Axios** - Centralized HTTP client for API communication
- **Lucide React** - Modern SVG iconography

### **Backend & Deployment**
- **Node.js & Express** - RESTful API backend handling authentication and data management
- **Vercel** - High-performance cloud deployment and static hosting

## ⚙️ Getting Started Locally

Follow these instructions to set up the project locally on your machine.

### Prerequisites

* **Node.js** (v16 or higher recommended)
* **npm** or **yarn**

### 1. Clone the Repository

```bash
git clone [https://github.com/your-username/walk-in-finder.git](https://github.com/your-username/walk-in-finder.git)
cd walk-in-finder

```

### 2. Configure Environment Variables

Create a `.env` file in your client and server folders as needed to point to your local development endpoints (e.g., `VITE_API_URL=http://localhost:5000`).

### 3. Install Dependencies & Run

```bash
# Install client dependencies
cd client
npm install

# Run the development server
npm run dev

```
